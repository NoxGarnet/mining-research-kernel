# Synthetic Zotero reading capture

This is an authored software fixture, not a real paper, library export, or
engineering conclusion. Its item keys, title, and page text are invented.
The digest describes the selected tool-response text, not a PDF file.

Use the [Zotero reading guide](../../docs/ZOTERO_READING.md) with an existing
project outside this repository. Import this fixture only with
`--task-context synthetic`; the record command never contacts Zotero.

An optional synthetic finding can use this shape:

```json
[
  {
    "statement": "The fabricated page describes matching boundary conditions.",
    "citation": {"attachment_key": "ATTACH01", "start_page": 1, "end_page": 1}
  }
]
```

The statement is a recorded interpretation with a locator. The software does
not establish that the page supports it or that the comparison is valid.
