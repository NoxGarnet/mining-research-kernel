# First FLAC3D research task

Use this as an Agent workflow for a bounded question. It does not promise a
complete model check or live solver execution.

1. Read the project entry and restate the question, scope, and intended output.
2. Ask for or locate the relevant project inputs. Record their paths; do not
   infer missing files, parameters, or results.
3. Confirm the FLAC3D version from project evidence or the user. If unknown,
   mark it unknown and do not claim a version-specific command check.
4. Identify the applicable official Itasca documentation for that version
   before relying on command names or parameter meaning. Record the page and
   what was actually checked.
5. Based on the current goal and authorization, choose one limited inspection
   or check. Distinguish file inspection, documentation review, static checks,
   and a real solver run. A registered adapter does not establish tool
   availability; real execution requires an available environment and
   task-specific authorization.
6. Report findings, sources, limits and unchecked items. Update `START.md`
   with the current understanding, remaining gap, and next action.

Do not present synthetic fixtures as FLAC3D results. Keep raw inputs intact;
the project entry should link to them rather than copy or replace them.
